Viagens - Landing Page

Este projeto é uma landing page criada para praticar HTML e CSS.
A página contém um banner com imagem de fundo e três seções: TripMe, MeetUs e Advice.

A navegação é interna, usando links que levam para cada parte da página.
Todo o visual é feito somente com HTML e CSS, sem JavaScript.

Arquivos do projeto:
- index.html
- style.css

No final da página há uma assinatura simples indicando o autor: Desenvolvido por Andreh.
